## v1.0.0 — 첫 릴리즈

OnGodMatchu 첫 정식 릴리즈입니다. 퀴즈 생성·풀이·채점부터 인증, 프로필, 소셜 기능까지 핵심 흐름을 모두 담았습니다. 개발자 관점에서 어떤 기능과 계약이 들어갔는지 영역별로 정리했습니다.

### 인증 · 계정

- 이메일 가입 — 인증코드 발송(Rate Limiting) → 자동 로그인까지 단일 흐름으로 통합
- OAuth2 소셜 로그인 — Google / Kakao / Naver. 가입 시 랜덤 닉네임 자동 부여 + 변경 API
- 비밀번호 정책 — NIST SP 800-63B 기반(길이·공백·이메일/닉네임 동일 차단 + HIBP 유출 대조)
- 닉네임 정책 통일 — 2~10자, 실시간 중복 체크 엔드포인트(`check-nickname`)
- 약관 동의 — 가입 시 강제 동의 기록(`TermsPolicy`) + 만 14세 이상 확인. OAuth/기존 사용자는 미동의 시 인터셉터로 게이트
- 회원 탈퇴 — soft delete, 2-step 모달 + 이메일 인증코드 + 사유 입력. 관리자 소유권 이전 처리
- 토큰 — JWT + refreshToken 인터셉터, 새로고침 시 세션 복원

### 퀴즈 만들기 · 풀이

- 만들기/편집 — stepper 기반 통합 플로우, 문제/정답 영역 분리 관리
- 풀이 — 문제별 정답 피드백 + 「제출 → 다음 문제」 흐름, 일괄 제출 Attempts API
- 채점 — 서버 채점 + 주관식은 Claude Haiku AI 채점
- 결과 화면 — 타이머, 점수 분포 차트, 오답 시 정답 이미지 노출
- 공개/비공개(`isPublic`) 상태, 카테고리 10종 확정
- 메인 목록 — 플레이 수 우선 정렬, 카테고리 필터, 카드 메트릭

### 이미지 파이프라인

- S3 Presigned URL 업로드 — key 기반 페이로드, `pending` 태그로 orphan 정리
- 공용 이미지 편집 모달 — 크롭/회전/반전, 원본 보존 후 재편집 가능(변환 메타 저장)

### 프로필 · 통계

- 프로필 페이지 — nested 라우팅(Layout/Sidebar/TabBar), 정보 수정 · 비밀번호 변경 · 이미지 업로드
- 통계 블록 — 내가 만든 퀴즈 / 내가 푼 퀴즈(solvedCount, 평균 정답률) 집계

### 소셜

- 퀴즈 스타(좋아요) · 댓글 · 공유하기
- 익명 사용자 추적 — 비로그인 풀이도 attempts 익명 저장(작성자 통계 반영), 공유 카운트 중복 방지
- 헤더 방문자 블록 — 일자별 고유 방문자 누적 합산

### 공지 · 릴리즈 노트

- 공지사항 / 릴리즈 노트 페이지(`/announcements`) 신설
- 정적 markdown 기반 관리 — Notice 도메인은 markdown 전환, 릴리즈 노트는 FE manifest + md 메타로 운영

### 플랫폼 · 인프라

- FE: React 18 + TypeScript + Vite, S3 + CloudFront 배포
- BE: Spring Boot + PostgreSQL, Flyway 마이그레이션, EC2 배포(GHCR 이미지)
- 운영 환경변수 분리(API base URL, `FRONTEND_URL` 기반 CORS), 프록시 `X-Forwarded-*` 신뢰 설정
- FE/BE 각각 유닛 테스트 + Swagger/OpenAPI 문서, GitHub Actions CI/CD 독립 구성
